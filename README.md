# lucajanken.github.io

Personal website of Luca Janken. Plain HTML, CSS and JavaScript, no build step.

```
index.html            all page content
assets/css/style.css  layout, typography and the light/dark colour tokens
assets/js/main.js     theme toggle, nav highlighting, copy-email button, contact form
assets/img/           profile photo and link-preview image
assets/files/         talk slides and other downloads
```

The contact form posts to [formsubmit.co](https://formsubmit.co), which forwards
messages to luca.janken@math.au.dk. The first submission triggers an activation
email that has to be confirmed before messages are delivered.
